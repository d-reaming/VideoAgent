VideoAgent —— 视频多模态 RAG + 多 Agent 问答系统
技术栈: Java · Spring Boot · LangChain4j · Kafka · Redis · Redisson · MySQL · PostgreSQL(pgvector) · Qwen-VL · Whisper/ASR
项目简介: 面向长视频/视频课程的多模态检索增强（RAG）与多 Agent 问答后端：上传后经 Kafka 事件驱动完成 ASR 转写、画面语义抽取、OCR 字幕三通道解析并统一写入"向量+关键词"双路索引；问答侧以 LLM 意图分类路由，经 RAG 检索与多 Agent 协作生成带引用答案，并对所有时间戳引用做确定性校验以防模型编造。
  • 分片上传 + 幂等去重 + 并发控制 — 5MB 分片断点续传、Redis 记进度，合并前查缺校验；Redisson 分布式锁保证 complete/消费幂等，并发下不重复入库、不重复建任务。
  • 多路解析与证据管理 — Whisper ASR + 关键帧 Qwen-VL + OCR 字幕并行解析，统一为 Evidence 多模态协议并对齐时间戳；OCR 字幕作画面文字权威源校正 ASR 专名。
  • 问答模式路由与双路检索 — DeepSeek LLM 意图分类路由概述/定点/画面/分析/通用五模式；pgvector 向量 + 关键词倒排正交混合召回，概述走 map-reduce 全片归纳。
  • 意图-执行-监督三角色 Agent 协作 + Function Calling 封装 — 意图识别者以 LLM 分类与 Planner 拆解目标，执行者以 Function Calling 调检索工具生成回答，监督者结构化验收、针对证据缺口与失实引用定向补证回炉；Agent 预算与轮次上限防失控。
  • 数据一致性与可靠性 — MySQL 为源真相 + Redis 缓存的读写一致，跨库最终一致靠定时对账；失败自动重试、上限转 DEAD 死信台账兜底，防重复/不一致。
  • 崩溃恢复与优雅降级 — 管道崩溃自动续跑，向量索引按 indexed_seq 断点续传不重做已入库批次；ASR/Embedding/检索不可用逐级降级，不阻断主链路。
